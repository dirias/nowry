FR-069
A row owns a destination
No route, no row. This is the rule the carousel could not have passed: quizzes and diagrams are card types inside a deck, so neither has anywhere to open.
in  Study, Books, Annual planning
out  Quizzes, Diagrams, the pet
FR-070
A done row stops inviting
It keeps its place, takes a check, drops its prompt and its chevron, and stops being a control at all. Progress stays legible without asking for the same thing twice.

FR-071
No answer means open
Loading, failed, or a payload in a shape nobody expected: all three leave the row open. Suggesting something already done is mildly redundant. Ticking a box on no evidence is a lie.
still loading  →  open
request failed  →  open
unexpected shape  →  open
The last rule has a second job: one dead signal can never let the panel decide everything is finished and retire itself for a user who never saw a working row.
